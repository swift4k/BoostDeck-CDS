# Changelog

## Initial public source-build project

- Integrate original blue-tile dashboard with wider layout and US-units improvements in one build.
- Retain native live CDS readings for coolant, oil, RPM, road speed, estimated fuel, power, and torque.
- Add isolated Mac build workflow, compatibility checks, guarded installation, local backup, disable/enable and restore helpers.
- Add preview generation, offline validation, CI, security and licensing documentation.

**Not included:** M Sport segmented RPM/speed gauges, precompiled BMW binaries, NBT Evo/QNX support, or universal compatibility guarantees.
